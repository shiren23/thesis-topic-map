决策树
  • 毕业论文选题构思
    • 一、素材与起点
      • 竞赛题：基于量子机器学习的医疗保险费用预测（回归任务）
      • 我的实现：RMSE ≈ 9006 / 8878（远逊于优秀答案）
      • 优秀答案（观星量仔队）：RMSE 4344
        关键改进 = 按 charges 分成 >10000 / ≤10000 各训一个模型（"分桶"）
      • 选题示例：氟骨症 X 线影像分级
        提供可借鉴的"三段式"结构：表征学习 → 长尾/等级 → 可靠性评估
      • 🌱 论文的种子（关键现象）
        charges 右偏/长尾 → 高费用尾部系统性失效；分桶有效但缺乏机理解释
    • 二、总原则（约束）
      • 问题研究 ≠ 工程报告：要有可回答的研究问题与机理
      • 结论必须有边界、不夸大；允许输给经典方法
      • 必须保留经典 ML 对照，否则说服力不足
      • 数据偏小 → 需扩充公开数据集 + 合成长尾 + 交叉验证
    • 三、决策一：创新锚点落在哪一层？
      • A · 量子编码 / 线路层未选
        取舍：量子含量强、贴合 2026 赛题；但易滑向工程对比，研究问题难做深
      • B · 长尾 / 分布感知层✓ 选定
        取舍：研究问题最实、机理可挖、天然贴示例选题；风险 = 量子易成"装饰"（需专门设计量子侧机制）
      • C · 不确定性 / 可靠性层未选
        取舍：最易出结论、工作量轻；但量子成分弱，导师若重量子创新则不宜
      • D · 三段式综合未选
        取舍：结构最漂亮、最像"优秀论文"；但工作量最大、易面面俱到而不深
      • 结论：选 B；把 A（编码）与 C（可靠性）作为配套章节补入
    • 四、决策二：B 内部怎么做？
      • B1 · 纯迁移研究未选
        取舍：最稳、最易完成；但量子创新弱（量子只是骨干）
      • B2 · 迁移 + 量子侧缓解✓ 选定
        取舍：真问题 + 真量子创新、工作量可控；代价 = 需实现并调通量子门控
      • B3 · 量子门控为唯一主线未选
        取舍：最聚焦、最有亮点；但本科难度与风险最高
    • 五、最终设计（B2）
      • 题目：长尾目标下量子-经典混合回归的失效机理与分布感知缓解方法研究
      • 研究问题
        • ① 尾部失效的机理是什么？
        • ② 经典不平衡回归方法能否迁移到混合 QML？
        • ③ 能否用参数更少的量子门控模型替代"分桶"？
      • 研究内容（三段式）
        • ① 失效机理诊断：竞争假设 H1( MSE 主导 ) / H2( 尾部稀缺 ) / H3( 分桶=条件建模 )
        • ② 方法迁移评测：重加权 / LDS·FDS / 两阶段 / 分位数
        • ③ 量子侧缓解：(a) 加权读出 · (b) 量子门控混合 · (c) 量子分位数
        • ④（可选）尾部可靠性评估待定
          是否保留，需与导师确认
      • 实验矩阵
        • 数据：保险集 + 2–3 公开回归集 + 合成可控长尾
        • 目标处理：全局 / 分桶 / 重加权 / LDS / FDS / 两阶段 / 分位数
        • 对照：经典 MLP + 相同目标处理（必需）
        • 指标：总 RMSE + 分组 RMSE（≤10k / 10k–15k / >15k） + 尾部偏差 + 参数量
        • 边界：样本量 × 长尾比例 × 比特数 × 噪声
        • 消融：门控专家数、编码方式在长尾下的差异
      • 预期结论：失效主因＝条件分布异质 + MSE 主导；量子门控以更少参数接近/超越分桶；样本量大或尾部比例高时差距收敛
      • 创新点：① 不平衡回归向混合 QML 的迁移性研究 ② 量子门控/条件混合回归 ③ 失效机理的实证分解与边界
      • 风险与对策
        • 门控不收敛 → 回退"加权读出"，主线仍成立
        • 迁移无效 → 负结果本身有价值，如实报告
        • 数据太小 → 公开集 + 合成 + 交叉验证
    • 六、待定 / 开放问题
      • 是否保留"可靠性"章节待定
      • 需确认：算力 / 本源真机 · 可支配时间 · 导师对量子创新的要求强度待定
      • 数据集扩充清单（Concrete / Energy / Yacht …）待定
